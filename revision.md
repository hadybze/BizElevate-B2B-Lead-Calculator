# UI Copy Revision Plan — Outbound Calculator

This document lists **copy-only changes** required to improve clarity, authority, and conversion for the standalone Outbound Calculator page.

Scope rules:

* Copy only (no layout, styling, or logic changes)
* Standalone calculator page
* Navigation simplified to **Calculator only** (remove Home / Services / About)

---

## 1. Navigation

### Current

* Home
* Services
* About
* Calculator

### Revision

* **Calculator** (single item)

Rationale:

* This is a focused utility page, not a marketing site
* Reduces distraction and exit points
